Smart Queue Management System

A simple web app for managing a customer queue. Issue tickets, call the next customer, skip absent customers, and reset the queue.

Features

- Take a Number: Adds a new customer to the queue.
- Call Next: Shows the next customer as "Now Serving."
- Skip Customer: Sets aside a customer who isn't present.
- Reset Queue: Clears everything to start over.

Notes

The queue is stored in memory, so refreshing the page resets it.
